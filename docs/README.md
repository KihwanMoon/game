# 문서 지도

```
docs/
├─ 기획/   무엇을 만드는가          ── 게임의 정체성
├─ 설계/   어떻게 만드는가          ── 시스템·아키텍처
├─ 결정/   아직 안 정한 것          ── 미결 49건 · 공백 · 알려진 이슈
└─ 참고/   왜 그렇게 정했는가       ── 실측·판정 자료
```

## 어디부터 읽는가

| 상황 | 읽을 것 |
|:--|:--|
| **처음이다** | `기획/1_통합기획서` → `설계/1_통합시스템설계` |
| **다음에 뭘 만들지** | `설계/1_통합시스템설계` §6 통합 도입 순서 (A~F) |

## 규율 — 정본과 사본

이 저장소는 사본을 여러 개 들고 있다. **사본을 고치지 않는다. 정본을 고치고 다시 가져온다.**

| 사본 | 정본 |
|:--|:--|
| `.claude/rules/` · `ruff.toml` · `tools/` | Confluence `python-coding-standard` (v14) |
| `design/tokens/` | Claude Design 프로젝트 `fae25530-…` |
| `기획/1_통합기획서` · `설계/1_통합시스템설계` · `설계/8_디자인명세` (통합 뷰) | `기획/2_GDD_v2` · `설계/2_TDD_v2` 와 각 시스템 문서 |

**통합 뷰(`기획/1_통합기획서`·`설계/1_통합시스템설계`)는 정본이 아니다.** 시스템이 서로 어떻게 맞물리는지를
보여주는 문서이고, 수치와 세부는 언제나 정본에 있다.

현재 드리프트는 `결정/3_알려진이슈` §2 에 있다.
