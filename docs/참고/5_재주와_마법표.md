## 읽는 법 — 축 다섯

| 축 | 무엇을 정하나 |
|:--|:--|
| **형태** | 대상 하나인가(`단일`·`자신`) 칸에 떨어지는가(`범위`·`직선`·`연쇄`). 예고가 붙으면 **칸에 떨어지고 진영을 안 가린다** — 아군도 시전자도 맞는다 |
| **예고** | 0 이면 즉발. 1 이상이면 그 틱 수만큼 붉은 칸이 먼저 선다 |
| **시전 규율** (`cast_act`) | 시전 중 다른 행동을 어떻게 할 것인가. **잠금**(규칙표가 안 돈다) · **버팀**(돌되 끊는 행동이 「불가」) · **취소**(고르면 끊긴다) · **자유**(해도 유지) |
| **피격 취소** (`cancel_on_hit`) | 시전 중 맞으면 끊기는가. **시전 규율과 별개 축**이다 — 잠겨 있어도 맞으면 끊긴다 |
| **거는 것** | 피해와 별개로 얹는 상태. 피해 0 인 장판이 상태만 거는 자리다 |

**예고 1틱은 끼어들 틱이 0 이다.** 다음 틱 TELEGRAPH 가 ACT 보다 앞이라, 시전과 발동 사이에 아무도 행동하지 못한다 — 그 스킬들은 시전 규율이 무엇이든 결과가 같다.
