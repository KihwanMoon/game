# 비각 (祕閣)

**규칙표를 짜서 내려가는 로그라이크.** 사람이 조작하지 않는다 — 조건과 행동으로 된 표를
적어 두면 그것이 대신 싸운다. 이 게임에서 실력은 반응속도가 아니라 **무엇을 언제 하라고
적었는가**다.

> 비각에서 빠진 것은 세상에서도 빠진다. 서고는 기억이고, 매체는 권마다 다르다 —
> 1막은 판목과 활자다.

- 이름의 정본은 `docs/기획/4_세계관.md`, 1막은 `docs/기획/6_1막_인출방.md` 다.
- **지도는 `docs/README.md`** 다. 기획·설계·결정·참고 네 갈래로 나뉜다.
- 개발 규약·환경·배포는 `CLAUDE.md` 를 본다.

## 빠르게 돌려 보기

```bash
uv sync --group dev          # .venv 구성
uv run pytest                # 테스트
./tools/check_all.sh         # 저장소 전량 게이트 — 커밋 전에 한 번

cd frontend && npm ci && npm run dev   # http://localhost:8090
```

서버가 없어도 게임은 돈다. 코어가 브라우저 안에서 직접 돌고, 서버는 **보관과 검증**만
맡는다 — 결과를 받지 않고 재시뮬해서 확정한다 (`docs/설계/7_변조방지`).
