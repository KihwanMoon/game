# scripts

운영·일회성 스크립트. 여기 있는 것은 게임 코어가 아니므로 `game/` 안에 두지 않는다.

들어올 것 (로드맵 기준):

| 스크립트 | 시점 | 용도 |
|:--|:--|:--|
| 헤드리스 배치 러너 | Phase 1 W3 | 표준 규칙표 × 1,000런 → 층별 승률·평균 틱 (TDD §10) |
| 룸 생성 검증 | Phase 4 W14 | 10,000회 생성 → 도달 불가 방 0건 |
| DSL 퍼저 | Phase 2 | 무작위 규칙표 → 크래시·무한루프 0건 |

배치 결과 리뷰는 매주 금요일에 한다 (로드맵 §10). 밸런싱을 감이 아니라 데이터로
하는 것이 결정론 코어를 최우선에 둔 실질적 이유다.
