# resources

코드가 아닌 데이터. 밸런스 수치는 코드에 하드코딩하지 않고 전량 여기 JSON 으로 둔다
(TDD §2) — 데이터 수정만으로 재빌드 없이 튜닝하기 위해서다.

| 디렉터리 | 담는 것 |
|:--|:--|
| `balance/` | 엔티티 기준 스탯, 층 스케일 계수, 접사 테이블 |
| `rooms/` | 손으로 그린 룸 템플릿 (12×9 그리드) |

룸 템플릿을 손으로 만드는 이유는 TDD §7.2 에 있다 — 순수 랜덤 그리드는 전술적으로
무의미한 공간을 대량 생산한다. 생성 직후 flood fill 로 `시작점 → 모든 문` 도달 가능성을
검증하고, 실패하면 재생성한다.

이 디렉터리의 JSON 은 Phase 3 에서 TypeScript 코어로 그대로 이식된다 (TDD §1.2).
파이썬에만 있는 표현에 기대지 않는다.
