# 파이썬 코드 작성 규칙

규칙 정본: Confluence 라벨 `python-coding-standard` 문서 (RULESET_VERSION 14)
규칙을 바꿔야 하면 이 파일이 아니라 정본 문서를 고치고 `/apply-conventions` 를 재실행한다.

## 네이밍
- 함수·메서드: {동사}_{목적어} snake_case. 동사는 허용 목록에서 선택.
- 목록의 어떤 동사도 그 동작을 정확히 뜻하지 못하면 다른 동사를 쓰되,
  `# naming: allow <사유>` 로 예외임을 드러낸다.
- 변수: 명사 snake_case. 동사로 시작하지 않는다.
- 변수 이름은 뜻을 담는다. 타입을 접미로 붙이지 않고(`name_s`), 한 글자 이름은
  관용이 확립된 자리에만 쓴다. 루프 변수도 무엇을 도는지 담는다 —
  `for t in turns` 가 아니라 `for turn in turns`.
- 축약은 이미 통용되는 것만 쓰고 새로 만들지 않는다(idx·ctx·cfg).
- 불리언: is_ / has_ / should_ 접두어.
- 클래스: 명사 PascalCase.
- 모듈 전역 상수: 대문자 SNAKE_CASE. 그 외 식별자는 소문자.
- 내부 전용: 단일 밑줄 접두어.
- 클래스 메서드는 클래스명이 목적어 역할을 하므로 동사 하나로 족하다
  (PROMPTS.get(), STATE.save_relation()). 동사 목록 규칙은 그대로 적용된다.
- 술어 함수(is_/has_/should_/can_)와 외부 인터페이스를 따르는 이름은 예외.
  라우트 핸들러·pydantic 밸리데이터·pytest 픽스처는 데코레이터로 자동 면제된다.
  프레임워크가 이름으로 읽어 가는 속성(arq 의 redis_settings 등)도 같다 —
  바꾸면 예외 없이 조용히 기본값으로 떨어진다.

## 구조
- 같은 로직 3회 반복 또는 함께 수정되어야 하는 2회 반복이면 함수로 추출.
- 2개 이상 파일에서 쓰이면 공용 모듈로 분리하고 import.
- 함수 50줄 초과, 순환 복잡도 10 초과, 모듈 400줄 초과 시 분해.
- 가변 전역 상태와 global 키워드는 금지.
  예외는 시그널 핸들러의 종료 플래그 하나이며 사유 주석을 남긴다.
- 디렉터리 이름은 역할을 말한다. 프레임워크 이름이나 무의미어를 쓰지 않는다(12장).

## 독스트링
- 구글 스타일. 공개 모듈·클래스·함수·__init__ 에 필수.
- 첫 줄은 명령형 한 문장. Args는 실제 시그니처와 일치.
- Args 한 항목이 두 줄을 넘으면 이어지는 줄을 더 깊이 들여쓴다.
  같은 깊이로 두면 콜론 없는 새 항목으로 읽혀 파싱이 실패한다.
- 값을 돌려주면 Returns(제너레이터는 Yields)를 적는다.
  함수 이름을 되풀이하는 문장은 없는 것만 못하다 — 빈 값·None·단위처럼
  호출자가 알아야 할 것을 적는다.
- Raises 에는 이 함수가 직접 던지는 예외를 적는다. 다만 라우트 핸들러·공개
  파사드처럼 전파가 곧 계약인 자리에서는 전파되는 예외도 적는다(게이트는 이 항목을
  검사하지 않으므로 정확성은 네가 책임진다).
- 타입 힌트는 실제 타입과 일치해야 한다. 게이트는 존재 여부만 본다 —
  확신이 없으면 좁히지 말고 넓은 타입을 쓴다. 틀린 애너테이션은 없는 것보다 나쁘다.
- 타입은 타입 힌트로 표현하고 독스트링에 중복 기재하지 않는다.
- 소문자가 정확한 표기인 고유명(ffmpeg, ack 등)은 문장 첫머리에서도 그대로 둔다.

## 주석
- 무엇이 아니라 왜를 적는다.
- 우회 처리, 성능 트레이드오프, 도메인 유래 상수, 의도적 미처리 예외,
  동시성·순서 의존성에는 주석을 필수로 남긴다.
- 주석 처리된 죽은 코드는 커밋하지 않는다.

## 작업 절차
- 파일 수정 후 별도 명령을 돌릴 필요는 없다. PostToolUse 훅이 포맷·린트를
  자동 적용하고, 자동 수정되지 않는 위반은 훅이 되돌려 알려 준다.
- 훅이 위반을 알려 오면 그 자리에서 고친다. 억제로 넘기지 않는다.
- 훅은 방금 쓴 파일 하나만 본다. 저장소 전량은 `tools/check_all.sh` 가 본다 —
  커밋 전에 한 번 돌린다.
- 검사 결과는 종료 코드로 판정한다. 출력 줄을 세는 방식은 도구의 출력 형식이
  예상과 다르면 0 을 돌려주고, 그것이 "위반 없음"과 구별되지 않는다.
- 새 공용 함수를 만들기 전에 기존 모듈에 같은 기능이 있는지 먼저 검색한다.
